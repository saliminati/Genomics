# Virtual NGS Lab — Module 1

This package contains a self-contained interactive HTML prototype and Claude-friendly project context.

## Goal
Build an interactive undergraduate virtual lab that teaches bacterial genomic DNA preparation for an Illumina iSeq 100 workflow.

## Module 1
Colony → Culture → Cells → Purified DNA → QC

The extraction portion follows the agreed Quick-DNA Miniprep Plus Biological Fluids & Cells workflow. Upstream culture and harvest are kept separate from the kit protocol.

## Claude
Upload `virtual_ngs_lab_module1.html` to Claude or add these files to a Claude Project. `CLAUDE.md` provides project instructions and `PROJECT_SPEC.md` provides the curriculum/product specification.

## Important
The HTML is an educational simulation, not a laboratory SOP. For real work, use the current manufacturer protocol and your institution's approved procedures.

## Recorded Actions Export
The lab includes **Save Recorded Actions**, which downloads the current electronic lab notebook/progress as a JSON file. **Reset Recorded Actions** clears the saved browser state and recorded actions after confirmation.
